Groq API Guide / Rehberi

Groq API Anahtarı Nasıl Alınır?

Aşağıdaki basit adımları takip ederek yapay zeka özelliğinde kullanmak üzere ücretsiz bir Groq API anahtarı edinebilirsiniz:

1. Konsola Gidin:

console.groq.com adresini ziyaret edin.

2. Giriş Yapın / Kaydolun:

Google veya GitHub hesabınızla hızlıca giriş yapın ya da yeni bir e-posta adresiyle kaydolun.

3. API Keys Bölümüne Geçin:

Sol taraftaki menü çubuğundan "API Keys" seçeneğine tıklayın.

4. Yeni Anahtar Oluşturun:

Açılan sayfada yeşil renkli "Create API Key" butonuna tıklayın.

5. Anahtarı İsimlendirin ve Kaydedin:

Anahtarınıza bir isim verin (örneğin: Quiz App) ve "Create" butonuna basarak anahtarınızı oluşturun.

6. Anahtarı Kopyalayın:

Ekranda beliren API anahtarınızı (genellikle gsk_ ile başlar) kopyalayın. Güvenliğiniz için bu anahtarı başka bir yerde göremeyeceğiniz için hemen kopyaladığınızdan emin olun.

7. Uygulamada Kullanın:

Kopyaladığınız anahtarı "Learn with AI" sayfasındaki "Insert Groq API" kutusuna yapıştırın. Sistem anahtarı otomatik test edecek ve geçerliyse yeşil bir onay işareti gösterecektir.

💡 Önemli Not: Groq API kullanımı bireysel geliştiriciler ve denemeler için belirli limitler dahilinde tamamen ücretsizdir. API anahtarınızı kimseyle paylaşmayınız.

How to Get a Groq API Key?

Follow these simple steps to obtain a free Groq API key for the AI translation evaluation feature:

1. Go to the Console:

Visit the Groq Console at console.groq.com.

2. Sign In / Sign Up:

Quickly log in using your Google or GitHub account, or sign up with your email address.

3. Navigate to API Keys:

Click on the "API Keys" option in the left sidebar menu.

4. Create a Key:

Click the green "Create API Key" button on the top right.

5. Name and Generate:

Enter a name for your key (e.g., Quiz App) and click the "Create" button.

6. Copy Your API Key:

Copy the generated key (usually starts with gsk_). Make sure to copy it immediately, as it won't be shown again for security reasons.

7. Paste in the Application:

Paste the copied key into the "Insert Groq API" text box on the "Learn with AI" page. The app will verify it and display a green checkmark if successful.

💡 Note: Using the Groq API is completely free within standard rate limits for developers. Never share your API key with anyone.
